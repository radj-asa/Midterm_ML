# Project Descriptions

## 1. Transaction Fraud Detection (Classification)

This project focuses on detecting fraudulent transactions using machine learning classification models.

Main workflow:

* Data preprocessing
* Missing value handling
* Feature encoding
* Model training
* Hyperparameter tuning using Optuna
* Experiment tracking using MLflow

---

## 2. Song Release Year Prediction (Regression)

This project focuses on predicting song release year using regression models based on numerical audio features.

Main workflow:

* Data preprocessing
* Regression modeling
* Model evaluation
* Hyperparameter tuning
* Model interpretation using LIME

---

## 3. Clustering Project

This project focuses on unsupervised learning using clustering techniques to identify hidden patterns and group similarities within the dataset.

Main workflow:

* Data preprocessing
* Feature scaling
* Clustering model training
* Cluster visualization
* Cluster evaluation
